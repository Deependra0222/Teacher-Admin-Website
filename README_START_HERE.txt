SMARTATTEND - OFFLINE BUILD KIT
======================================

FILES
- SmartAttend_Codex_Offline_Guide.html : complete, self-contained interactive handbook. Open with Chrome, Edge or Firefox; no internet needed to read it. Check days and add notes; download a progress JSON frequently.
- SmartAttend_Codex_Build_Guide.pdf : printable PDF with every step and all prompts.
- SmartAttend_Codex_Prompts.txt : copy-and-paste prompt archive for Codex.

START HERE
1. Open SmartAttend_Codex_Offline_Guide.html in your browser.
2. Read "Read this first", then "First-time setup".
3. Install Android Studio, create the SmartAttend starter project.
4. Open that same folder in Codex.
5. Paste prompt P0, then test; proceed through prompts P1, P2, etc.
6. Keep PROJECT_STATUS.md and use Git checkpoints.
7. Before each break, export progress from the HTML guide and back up your actual Android project folder.

IMPORTANT
The handbook files do NOT include your future generated Android app. You must back up that app separately.
Simulated classroom presence is DEMO ONLY until physical ESP32 integration is implemented and validated.
Your progress checkmarks use browser localStorage, not an online account. Exporting progress to JSON gives you a portable copy.
External official documentation links require internet, but the handbook and prompts themselves work offline.
